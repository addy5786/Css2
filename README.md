# HTML and CSS Advanced Practical Assignments

## 📌 About the Project

This project contains practical exercises designed to develop skills in HTML5 and CSS3. It covers Flexbox properties, responsive web design, media queries, background videos, dark mode, navigation bars, cards, styled tables, and interactive feedback forms.

## 🎯 Objectives

- Understand and implement Flexbox layout properties.
- Create responsive web pages using CSS media queries.
- Use orientation and dark-mode preferences to adapt webpage content.
- Build responsive navigation bars and card layouts.
- Style tables using pseudo-classes and pseudo-elements.
- Create interactive forms with validation-friendly styling.
- Apply CSS animations, transitions, transforms, and gradients.

## 📝 Assignments Included

### 1. Flexbox Properties
Demonstrate the following Flexbox properties using five items inside a flex container:

- `flex-direction`: row, row-reverse, column, column-reverse
- `flex-wrap`: nowrap, wrap, wrap-reverse
- `justify-content`: flex-start, flex-end, center, space-between, space-around, space-evenly
- `align-items`: flex-start, flex-end, center, stretch, baseline
- `order`: rearrange items without changing HTML
- `flex-grow`: distribute available space among items

### 2. Welcome Page with Media Queries
Create a welcome page with a heading, paragraph, and background color. Use a `max-width` media query to change the background color, heading text color, and paragraph font size on smaller screens.

### 3. Responsive Travel Page
Create a travel page with a background image. Use a `min-width` media query to change the background image, heading and paragraph colors, font sizes, and text transformations on wider screens.

### 4. Responsive Background Videos
Create a website welcome page with landscape and portrait background videos. Use the `orientation` media feature to display the appropriate video and keep the heading readable.

### 5. Dark Mode with Videos
Create a page that displays “Hello, Sunshine” over a daytime video by default. Use `prefers-color-scheme: dark` to switch to “Hello, Moonlight,” a nighttime video, and suitable text and button colors.

### 6. Responsive Navbar and Cards
Create a webpage containing:

- A navbar with Home, Services, Gallery, and Contact links.
- Three cards with images, headings, and descriptions.
- Flexbox layouts, borders, rounded corners, and shadows.
- A media query that stacks the navbar links and cards vertically on smaller screens.

### 7. Styled Student Marks Table
Create a Student Marks table with at least six data rows and five columns.

Features include:

- Full-width table with merged borders and centered text.
- A centered container with maximum width and box-shadow.
- Alternating row colors using `:nth-child(odd)`.
- A colored table header.
- Grade icons using the `::after` pseudo-element.
- An animated multicolor gradient background using `@keyframes`.
- Row hover effects with smooth transitions.
- Cell hover transformations using `scale()`, `rotate()`, and `skew()`.

### 8. Interactive Feedback Form
Create a centered Feedback Form containing:

- Name, email, and phone number fields.
- Rating radio buttons.
- Service type dropdown.
- Comments textarea.
- Contact consent checkbox.
- Submit button.

**Styling features:**

- Gradient background and a centered form container.
- Rounded corners, shadows, and maximum width.
- Full-width inputs with padding and rounded borders.
- `:focus` effects with border colors and glow.
- Button hover colors, transitions, and transforms.
- Styled `::placeholder` text.
- Required-field asterisks using `::after`.
- Fade-in and slide-up animation using `@keyframes`.
- Responsive layout using a media query.

## 🛠️ Technologies Used

- **HTML5** – Page structure, forms, tables, videos, and content.
- **CSS3** – Styling, layouts, animations, and responsive design.
- **Flexbox** – Flexible and responsive element alignment.
- **Media Queries** – Adapting layouts to screen size, orientation, and color scheme.
- **CSS Pseudo-classes and Pseudo-elements** – Interactive styling and decorative effects.
- **CSS Animations and Transitions** – Smooth visual effects.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the required HTML file in a browser.
4. Alternatively, use the Live Server extension in VS Code.
5. Resize the browser window to test responsive layouts.
6. Switch your system or browser color scheme to test dark mode.
